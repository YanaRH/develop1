На уроке 10.1
В этом уроке вы продолжите работать с системой контроля версий Git.

Познакомитесь с GitHub — сервисом, в котором хранят свои проекты разработчики. Привяжете ваш аккаунт GitHub к локальному репозиторию и настроите доступ через токен или SSH-ключ.
Изучите концепцию GitFlow — модели ветвления, которая помогает эффективно работать с Git в команде. Вы рассмотрите основные типы веток, которые используются в GitFlow.
Погрузитесь в работу с ветками. Ветки — это мощный инструмент, который позволяет работать над разными функциями и исправлениями в коде параллельно. Вы научитесь создавать, переключаться и удалять их.
Научитесь делать слияние веток, чтобы объединить несколько исправлений в одну единую историю изменений. Разберетесь, в чём разница между способами слияния 
merge
 и 
rebase
. В результате вы научитесь выполнять слияние веток в своем проекте, выбирая подходящий метод в зависимости от задачи.
Урок может показаться вам сложным и объемным. Советуем внимательно изучать материал: смотреть видео, читать конспект, выполнять задачи.

Обратите внимание на текстовые инструкции. В них вы найдете информацию, как работать с GitHub в разных операционных системах.

Про домашку
В домашнем задании этого урока вы продолжите работать над проектом. Отправите свой локальный Git-репозиторий на GitHub. Начнете работать по GitFlow, разделяя код на ветки, и расширите приложение дополнительными функциями работы с данными о банковских операциях пользователя.
На уроке 10.2
В этом уроке вы продолжите изучать ключевые аспекты разработки на Python и сфокусируетесь на тестировании кода.
Рассмотрите виды тестирования — юнит-тесты, интеграционные тесты и системные тесты. Вы узнаете, как каждый вид тестирования помогает обеспечить надежность и качество вашего кода.
Узнаете, как использовать инструкцию 
assert. Эта инструкция позволяет проверять, что условие выполняется, и если это не так, выбрасывает исключение. Вы рассмотрите примеры использования 
assert в тестах.
Изучите фреймворк pytest — инструмент для написания тестов на Python. Вы узнаете, как установить и настроить pytest, а также как использовать его для написания и запуска тестов.
Рассмотрите фикстуры — механизм, который позволяет определить и настроить начальное состояние для тестов. Вы также изучите параметризацию тестов, которая позволяет запускать один и тот же тест с различными параметрами.
Познакомитесь с TDD (Test Driven Development). Это тестирование, написание кода и рефакторинг. Вы поймете, как использование TDD может помочь вам создать более надежный и поддерживаемый код.
Погрузитесь в анализ code coverage. Это показатель, который позволяет определить, какой процент кода был покрыт тестами. Вы узнаете, как использовать инструменты для анализа code coverage и как это помогает создавать более надежный код.
Про домашку
Вы напишете тесты, используя pytest для функционала, который разработали в предыдущих домашках. Протестируете функции в разных сценариях поведения с помощью параметризации и используете фикстуры для подготовки входных данных для тестов.
На уроке 11
Рассмотрите, какие инструменты предоставляет Python для работы с последовательностями данных. Узнаете, как можно использовать конвейеры для обработки больших объемов данных. Поработаете с функциями 
map, filter, chain
 — основными строительными блоками для создания конвейеров.
Узнаете, как использовать генераторы списков. Это удобный способ создания списков в Python. Генераторы списков позволяют создавать новые списки из существующих данных в момент выполнения программы в одну строку кода. Это упрощает и ускоряет процесс работы с данными.
Рассмотрите генераторные выражения — инструмент для работы с коллекциями данных. Генераторные выражения позволяют создавать итераторы по запросу, что экономит память и ускоряет вычисления. Узнаете, что генераторные выражения отличаются от генераторов списков тем, что вычисляют значения только при необходимости.
Разберетесь, как работать с функциями-генераторами и как они могут быть полезны в вашей работе. Генераторные функции позволяют создавать бесконечные последовательности и избавляться от необходимости хранить все элементы в памяти. Вы узнаете, как работают функции-генераторы, зачем нужно ключевое слово 
yield и чем оно отличается от return.
Самостоятельно попрактикуетесь в решении задач с использованием генераторов конвейеров, генераторов списков и генераторных выражений, а также функций-генераторов. Научитесь тестировать различные виды генераторов с помощью pytest и конструкции 
assert.
Про домашку
В этой домашке вы будете реализовывать новый модуль для банковского приложения, который включает в себя фильтрацию транзакций по определенной валюте и получение описания каждой операции. Вы также научите приложение генерировать номера банковских карт для клиентов.
На уроке 11.2
Рассмотрите понятие замыканий в Python и их связь с декораторами. Это понимание важно при работе с декораторами. Замыкания позволяют сохранить области видимости и значения переменных в каждом конкретном случае.
Познакомитесь с концепцией декораторов в Python. Декораторы — это инструмент, который позволяет расширять возможности функций без изменения их исходного кода. Это очень удобно, когда требуется добавить новую функциональность к уже существующему коду, но изменять его нежелательно.
Поймете, что такое декораторы с параметрами и для чего они нужны. Часто необходимость передать в декоратор какие-то параметры возникает, если нужно настроить поведение декоратора для конкретной задачи. В этом уроке вы рассмотрите, как создавать декораторы с параметрами, на примере проверки аргументов функции. Вы научитесь создавать предикаты для валидации аргументов функции и компоновать их в сложные условия.
Познакомитесь с функцией 
wraps. Этот инструмент позволяет сохранить исходные атрибуты функции при ее оборачивании декоратором. Это полезно при отладке кода и документировании.
Разберетесь в тестировании декораторов. Как и любой другой код, декораторы могут содержать ошибки. Вы узнаете, как правильно тестировать декораторы на наличие ошибок и проверять, правильно ли они работают.
Про домашку
Вы будете реализовывать очередной модуль для банковского приложения, который включает в себя логирование информации о работе приложения в файл или консоль. Реализовывать такой функционал вы будете с помощью декораторов, не изменяя уже работающие функции.
